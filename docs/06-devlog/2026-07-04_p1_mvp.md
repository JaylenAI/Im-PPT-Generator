# 2026-07-04 — P1 MVP 관통 완료

## 한 일

프롬프트 → PPTX 다운로드 전 파이프라인을 실동작까지 구축.

1. **claude-cli 프로바이더**(`packages/core`): `claude -p --json-schema`로 구조화 출력(구독 기반, API 키 불필요). GC-Agent 설정 패턴 미러링(프로바이더 레지스트리·프롬프트-as-data·family 어댑터·시크릿 마스킹).
2. **생성 파이프라인**: generateOutline → generateSlide(레이아웃 contentSchema를 LLM 계약으로) → generateDeck(슬라이드 병렬 생성).
3. **exporter**(`packages/exporter`): 절대좌표 덱 → 편집 가능 PPTX(요소 7종, px→inch/pt, 토큰 해석).
4. **renderer**(`packages/renderer`): 절대좌표 React 렌더러(exporter와 동일 캔버스, SSR 안전 SVG 차트).
5. **API 라우트**(`apps/api`): 덱 생성/조회/Export/다운로드 + 카탈로그 + AI 설정. deps 주입 팩토리(오프라인 테스트).
6. **apps/web**: Vite+React 브라우저 MVP(프롬프트→생성→렌더→다운로드), flow-deck-creator 디자인 토큰 + 우리 renderer.
