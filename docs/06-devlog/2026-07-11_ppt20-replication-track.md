# Devlog — PPT 샘플 20선 재현·파생 트랙 (2026-07-11)

> 브랜치 `feature/ppt20-templates`. R1~R6(실측+시퀀스) 위에 1:1 정밀 수렴 + Phase B 파생을 2커밋으로 스택. 전 패키지 회귀 그린 + 실데이터 생성 검증.

사용자 요구: "`~/Downloads/PPT_샘플_20선` 이 양식 20개 그대로 + 그 느낌으로 딥서칭해 템플릿 모두 제작". 1차 산출물에 대해 **"복제하듯이 만든 게 안 보인다"**는 재지적을 받고, 팔레트만 바꾸는 리컬러가 아니라 **각 원본의 시그니처 표지·본문 구조까지 1:1 재현**하는 방향으로 전환했다.

## 1. 접근 — 시그니처 레이아웃 재현

원본 20장은 Pinterest식 세로 쇼케이스 핀(각 템플릿 팩을 세로로 타일링)이다. R1에서 ImageMagick 히스토그램으로 팔레트를 실측(`reference-specs/*.json` SSOT)하고, 각 원본의 표지·콘텐츠 유형을 육안 대조해 레이아웃을 재현했다.

- **표지 레이아웃 4종 신규**:
  - `masthead-cover` — 거대 타이포 마스트헤드(RE-SUME류). `dark` 옵션으로 검정 마스트헤드(HASU·Mono Proposal·Fashion Lookbook).
  - `editorial-headline` — 거대 하단 헤딩 + 원형 배지 + 대형 숫자 + 사진 블록.
  - `ring-cover` — 동심원 풀블리드(Orange Company류).
  - `report-cover` — 투톤 마스트헤드 + 우측 이미지 블록 + 연도 배지(비즈니스 플랜류).
- 모두 layout-as-code(순수 함수 → SlideElement)라 렌더러/익스포터 무변경.

## 2. 1:1 정밀 수렴 — 4 서브에이전트 병렬 대조

컨텍스트 절약을 위해 이미지 다량 판독을 4개 서브에이전트에 분담(각 4~5종)해 원본 대비 표지·시퀀스 갭을 도출하고 일괄 반영했다.

- **표지 배경 실측 교정(최대 미스)**: 원본이 다크/라이트/풀블리드 컬러인지 육안 크롭으로 확정.
  - 05 HASU·18 Mono → **다크 마스트헤드**(원본 검정 확인).
  - 20 Infographic → 밝은 레드가 아니라 **다크 네이비**(월드맵 배경) — 팔레트 primary 교정.
  - 10 → 라이트 에디토리얼, 02·11·12·19 → 라이트 리포트(우측 이미지 블록).
- **본문 시퀀스**: 20종 전부 범용 슬라이드(stat/chart/comparison)를 **원본 콘텐츠 유형별 시그니처**(team-grid·timeline·profile-split·metric-bars·steps-circles·dashboard-cards)로 교체.
- **사진**: 실 이미지 없으면 회색 플레이스홀더 블록(스톡 키 불필요, 사용자 승인).

## 3. Phase B — 파생 확장

"거기서 파생되는 다양한 템플릿" + "비슷하지만 다른 컨셉·분야" 요구에 대응.

- **팔레트 변형 47종 시퀀스 상속 수정**: 기존 변형이 낡은 범용 시퀀스를 쓰던 것을 베이스의 충실 시그니처 시퀀스 상속으로 교정(`ppt20BaseOf` 정규식). hero 지정 변형만 표지를 풀블리드 컬러로 교체해 브랜드 컬러 강조. 다크 마스트헤드 판별을 베이스 인식으로 확장(05·18 변형도 검정 상속).
- **분야 필드 14종 신규**(`themes/ppt20-fields.ts`): 스타트업 피치·논문 심사·제품 출시·헬스케어 리포트·교육 강의·비영리 연례보고·부동산 럭셔리·패션 룩북(다크)·레스토랑·콘퍼런스 키노트·투자자 리뷰·마케팅 캠페인·크리에이티브 포트폴리오·기술 백서. 분야별 팔레트 + 시그니처 레이아웃 재사용(신규 레이아웃 코드 0).

→ **PPT 패밀리 총 81종**(베이스 20 + 팔레트 변형 47 + 필드 14), 전체 카탈로그 **194종**, 레이아웃 **35종**.

## 4. 실데이터 생성 검증

신규 `fld-investor-review` 템플릿으로 **실제 데이터 기반 PPT 1개**를 풀 파이프라인 생성했다.

- 주제: "2024 글로벌 클라우드 인프라 시장 — 투자자 브리핑". 실측 수치(시장 3,300억달러·AWS 31%/Azure 25%/GCP 11%·분기 76→82→87→92)를 user_only 소스로 제공.
- 결과: **6팩트 추출 → 9슬라이드**(report-cover→agenda→dashboard-cards→chart→kpi-grid→metric-bars→comparison→closing→references), 인용 1·출처 1 역추적, $2.46.
- 검증: Action Title(전 슬라이드 결론 문장)·데이터 스토리텔링(차트 4분기 하이라이트)·시그니처 시퀀스 정확 반영. LibreOffice 렌더 육안 완성도 확인.

## 함정 기록

- masthead 폰트 폴백이 넓어 대형 헤딩(EDITORIAL/L 중간 줄바꿈) → fontSize 132→112 하향.
- zsh 배열은 1-인덱스 → 몽타주 라벨 밀림(연관배열/명시 매핑 사용).
- `magick montage`는 `-font /System/Library/Fonts/Helvetica.ttc` 필수, soffice PDF 변환은 단일 인스턴스라 순차만.
- 워크스페이스 tsx 스크립트는 `apps/api`에서 실행해야 `@im-ppt/*` resolve.
