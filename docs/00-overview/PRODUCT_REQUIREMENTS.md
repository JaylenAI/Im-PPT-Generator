# PRODUCT REQUIREMENTS — 기능/비기능 요구사항

> MoSCoW 분류. 근거: [경쟁 분석](../01-research/COMPETITIVE_ANALYSIS.md)의 Must-have 11축 + 사용자 핵심 요구. Phase 매핑은 [ROADMAP](../06-devlog/ROADMAP.md).

## Must Have (필수)

### 생성 파이프라인
- [ ] 텍스트 프롬프트 → 덱 생성 (장수/톤/청중/언어 옵션) — P1
- [ ] 아웃라인 생성 → 유저 편집/재정렬/승인 게이트 — P1
- [ ] 슬라이드 JSON 스키마 검증 생성 (실패 시 자동 재시도) — P1
- [ ] **슬라이드별 계획(디자인 의도+내용 요약) 보고 → 승인 게이트** ⭐차별화 — P4
- [ ] 자율도 레벨 L0(전자동)~L3(페이지별 승인) — P4
- [ ] 슬라이드 단위 재생성/레이아웃 스왑 — P4

### 리서치/그라운딩 (할루시네이션 제로)
- [ ] 웹 딥서치(검색 API+스크레이핑) + 유저 제공 URL/텍스트/문서 동일 취급 — P3
- [ ] 팩트 추출(소스 ID 부착) → **팩트 승인/거절 게이트** — P3
- [ ] 인용 체인: 소스→팩트→슬라이드 요소 `citationId` 역추적 + 소스 매니저 ⭐차별화 — P3

### 실시간 UX
- [ ] SSE 의미 단위 스트리밍 — **AI가 슬라이드를 그리는 모습 실시간 표시**(`slide_delta`) — P2
- [ ] 생성 중 재접속 시 이벤트 재생(잡 영속) — P2
- [ ] AI Copilot 챗 패널(덱/선택 슬라이드 문맥, 자연어 수정, 출처 칩) — P4

### 편집
- [ ] 페이지 선택 → 해당 페이지만 AI 수정 — P4
- [ ] WYSIWYG 수동 편집(텍스트/이미지/도형/차트/표/아이콘, 드래그/리사이즈, 속성 패널) — P5
- [ ] 오버플로 자동 보정(폰트 메트릭 계측→단계 축소) — P5
- [ ] undo/redo + 버전 히스토리 — P5

### 템플릿/디자인
- [ ] 템플릿 갤러리(카테고리/비율/컬러 필터) + 테마 시스템(디자인 토큰) — P1(2종)→P6(15종+)
- [ ] 브랜드킷(로고/팔레트/폰트) — P6
- [ ] **유저 PPTX 업로드 → 테마/레이아웃 추출 후 그 형식으로 생성**(v1은 제한적) — P6
- [ ] 적응형 레이아웃 — 콘텐츠가 넘쳐도 깨지지 않음(레이아웃=코드) — P1부터 구조로 보장

### 입력 확장
- [ ] PDF/DOCX/MD 업로드 → 덱 — P7
- [ ] 장문 붙여넣기 3모드(generate/condense/preserve) — P7
- [ ] URL 임포트, 기존 PPTX 콘텐츠 임포트, CSV→차트 — P7

### 차트/이미지
- [ ] 차트 7종(bar/hbar/line/area/pie/donut/scatter) + 인라인 데이터 편집 + 프롬프트→차트 — P1(기본)→P8
- [ ] AI 이미지 생성 + 스톡(Pexels) 폴백 혼합 — P8

### 출력/발표
- [ ] **PowerPoint에서 편집 가능한 고충실도 PPTX** + PDF — P1
- [ ] 16:9 / 4:3 / 9:16 — P1(16:9)→P9
- [ ] 발표 모드 + 발표자 뷰 + AI 스피커 노트 — P9
- [ ] 웹 링크 공유(읽기 전용) — P9

### AI 부가
- [ ] 덱 번역(일괄), 요약/확장/톤 리라이트 — P10

## Should Have

- [ ] 원클릭 팩트체크(근거 강/약 플래깅) — P3
- [ ] Guide Mode(청중/목적 사전 인터뷰) — P7
- [ ] 슬라이드당 디자인 변형 N개 제시→선택 — P8
- [ ] 컨설팅급 차트(워터폴/Mekko) ⭐시장 공백 — P8
- [ ] 접근성 검사(대비/알트텍스트) ⭐시장 공백 — P10
- [ ] 조회 애널리틱스, 예상 청중 질문 생성 — P10
- [ ] 생성 REST API + MCP 서버 — P10

## Could Have (v2 후보)

- [ ] 나레이션 MP4 export(보이스 클론), AI 리허설 코치
- [ ] 라이브 데이터 커넥터/Snapshots, 배치 개인화(CSV→N덱)
- [ ] Skills/템플릿 패키지 공유, 딜룸

## Won't Have (이번 범위에서 명시적 제외)

- ❌ SaaS: 인증/결제/크레딧/멀티테넌트 — **별도 승인 전 착수 금지**
- ❌ 실시간 다인 공동편집(CRDT) — v2
- ❌ 모바일 네이티브 앱 — 웹 반응형으로 대체
- ❌ 애니메이션/트랜지션 고도화 — 경쟁 제품도 전반적 약점, PPTX 호환 리스크 큼

## 비기능 요구사항

| 항목 | 목표 | 근거/비고 |
|---|---|---|
| 아웃라인 응답 | 10초 이내 스트리밍 시작 | 체감 대기 한계 |
| 슬라이드 1장 생성 | 15초 이내(이미지 제외) | slide_delta로 중간 표시 |
| PPTX export 충실도 | 웹 렌더와 시각 일치, 전 요소 PowerPoint 편집 가능 | Tome 교훈 — 생존 조건 |
| 폰트 | 안전 폰트 세트로 제한(exporter 검증) | 뷰어 폰트 부재 시 깨짐 방지 |
| 덱당 LLM 원가 | 텍스트 $0.5 이하 / 이미지 포함 $2 이하 계측 | provider 비용 집계 |
| 스키마 검증 실패 | 자동 재시도 2회, 실패 시 명시 에러(무성 폴백 금지) | |
| 보안 | API 키 서버 전용, `.env` 커밋 금지, 입력 zod 검증, PII 로그 금지 | |
| 테스트 | 커버리지 80%+, phase별 실데이터 E2E(목 금지) | [TESTING_STRATEGY](../05-guides/TESTING_STRATEGY.md) |
| 코드 | 파일 200~400줄(최대 800), 하드코딩 금지, 데이터계층 격리 | [CODING_STANDARDS](../05-guides/CODING_STANDARDS.md) |
