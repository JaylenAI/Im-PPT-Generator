# ADR-002: 레이아웃은 코드, AI는 선택+콘텐츠만 (AI 자유 디자인 금지)

- 상태: ✅ 확정 (2026-07-03)

## Context

LLM에게 좌표·크기를 자유 산출시키면 오버플로/겹침/불균형이 반드시 발생한다(업계 공통 경험). Gamma는 20+ 모델과 수년의 룰 튜닝, Canva는 1억 에셋으로 이를 덮지만 우리는 그 자원이 없다.

## Decision

레이아웃 변형(title/agenda/bullets/two-col/stat/quote/chart/closing, …)을 **`packages/templates`에 코드로 구현**하고, AI의 산출은 ① 레이아웃 키 선택 ② 스키마 검증되는 콘텐츠(텍스트/데이터)로 **제한**한다. 좌표·간격·타이포 배치는 레이아웃 코드가 소유한다. (Beautiful.ai Smart Slides / Presenton TSX+Zod 방식)

## Consequences

- (+) "콘텐츠를 넣어도 깨지지 않는다"가 기본값 — 적응형 레이아웃이 별도 기능이 아니라 구조
- (+) 스키마 검증 실패 시 재시도 루프가 명확한 계약을 가짐
- (−) 표현력 = 레이아웃 카탈로그 크기 → 템플릿 확장이 상시 백로그(P6+)
- (−) 레이아웃 코드 품질이 곧 제품 디자인 품질 — 레이아웃 추가 시 디자인 QA 필수
