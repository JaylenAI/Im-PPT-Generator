# ADR-005: 가상 캔버스 절대좌표 + 테마 토큰 참조

- 상태: ✅ 확정 (2026-07-03)

## Context

PPTX는 절대좌표(inch/EMU) 세계이고 리플로우가 없다. 웹 렌더러와 익스포터가 다른 좌표계를 쓰면 "웹과 PPTX가 다르게 보임"이 필연.

## Decision

- 좌표계: **가상 캔버스 px** — 16:9=1280×720, 4:3=1024×768, 9:16=720×1280 (`CANVAS_SIZES`). 렌더러는 px→CSS(스케일), 익스포터는 px÷96→inch 변환만.
- 색상: hex 리터럴 또는 **`token:colors.*` 테마 토큰 참조** 허용(정규식으로 스키마 강제). 해석은 렌더러/익스포터 공용 resolver.
- 폰트: 이름 참조 + **안전 폰트 세트 검증은 exporter 책임** (뷰어에 폰트 없으면 PPTX가 깨지므로).
- 텍스트 오버플로: 폰트 메트릭 계측 → 폰트 크기 단계 축소(P5) — 렌더러/익스포터 공용 모듈.

## Consequences

- (+) "웹에서 보이는 것 = PPTX" 시각 일치의 수학적 기반
- (+) 테마 교체가 데이터 수정 없이 전파(하드코딩 방지 스키마 강제)
- (−) 반응형 아님 — 비율 변경 시 레이아웃 변형이 비율별 배치를 소유해야 함(P9 스윕)
