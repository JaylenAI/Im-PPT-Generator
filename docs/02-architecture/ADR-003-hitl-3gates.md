# ADR-003: HITL 3게이트 + 자율도 레벨

- 상태: ✅ 확정 (2026-07-03)

## Context

핵심 요구: "AI가 페이지별로 어떻게 만들지 실시간 보고하고 허락받으며 제작". 14개 경쟁 제품 조사 결과 아웃라인 승인까지만 존재하고 **슬라이드별 계획 승인은 전무**(시장 공백). 반면 Manus는 게이트가 아예 없어 "중단해야 개입 가능"이 약점으로 지적된다.

## Decision

파이프라인에 게이트 3종을 정식 단계로 둔다: **① facts**(추출 팩트 승인/거절) → **② outline**(목차 편집/승인) → **③ slide_plan**(페이지별 디자인 의도+내용 요약 승인). 게이트는 `gate_waiting` SSE 이벤트로 표면화되고, 잡은 승인 입력까지 대기한다.
개입 피로를 막기 위해 **자율도 레벨**로 게이트를 선택 활성화한다: L0(전자동) / L1(②만) / L2(①+②) / L3(①+②+③).

## Consequences

- (+) 시장 공백 차별화 + 고부담 덱(IR/보고)의 신뢰 확보
- (+) 게이트가 스키마 이벤트로 정의되어 UI/API/잡이 같은 계약 공유
- (−) 잡이 장시간 대기 가능 → 잡 상태 영속+타임아웃 정책 필요(P2)
- (−) L3는 느림 — 기본값은 L1, 레벨별 UX 최적화 필요
